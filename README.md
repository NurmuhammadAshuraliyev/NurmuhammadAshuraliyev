## About

Full-stack engineer working on production ERP software used by real businesses.
Most of my time goes into designing service boundaries that stay honest under load —
tenant isolation that can't be bypassed, typed contracts between services, and
frontends that keep working when the network doesn't.

- 🔭 Building a multi-tenant ERP platform — HR, inventory, sales and finance modules
- 🧩 Working across five services: REST, GraphQL and gRPC in one system
- 🌱 Going deeper on distributed systems, message queues and observability
- 💬 Happy to talk about Node.js architecture, Prisma, or offline-first React
- 📫 Reach me at **ashuraliyevnurmuhammad16@gmail.com**
